# Media Disk Cleaner

Windows-приложение, которое помогает найти **свои** фото, видео и аудио и освободить место — без «магической очистки» диска и без прав администратора.

Программа **не удаляет файлы сама**. В корзину Windows попадают только те файлы, которые вы сами отметили, и только после подтверждения. Системные папки, программы и игры в список не попадают.

Подходит для Windows 10 и Windows 11. Обычная учётная запись, без UAC.

---

## Зачем это нужно

На диске часто лежат гигабайты старых снимков, роликов и музыки в «Загрузках», на рабочем столе и в пользовательских папках. Проводник плохо показывает, *сколько это весит вместе*. Системные «очистители» либо слишком агрессивны, либо трогают не медиа.

Media Disk Cleaner делает узкую работу:

1. Находит изображения, видео и аудио в выбранных папках или стандартных каталогах пользователя.
2. Показывает объём по категориям и таблицу файлов.
3. Даёт отфильтровать крупные и старые файлы, посмотреть превью и отправить отмеченное в корзину.

Карточки сверху считают **только найденное медиа**, а не всё занятое место на диске.

---

## Что умеет

- Быстрое сканирование стандартных папок пользователя (фото, видео, музыка, загрузки, рабочий стол, документы).
- Выборочное сканирование ваших каталогов. Корень диска сам по себе не сканируется.
- Таблица: поиск, фильтры по категории / типу / диску / размеру / дате.
- Предпросмотр картинки и сведения о файле.
- Перемещение **только отмеченных** файлов в корзину Windows.
- Журнал операций и технический лог.
- Отчёт в CSV и JSON.

Пока нет: поиск дубликатов, экспорт в PDF/DOCX.

## Как пользоваться

### Готовый EXE

1. Соберите один файл `build.bat` (см. ниже) или возьмите уже собранный `dist\MediaDiskCleaner.exe`.
2. Скопируйте **только этот exe** на флешку или другой ПК. Папки `_internal` и установщик не нужны.
3. Запустите обычным двойным щелчком, **не** «от имени администратора».
4. Выберите диск или добавьте папки, нажмите **Начать сканирование**. Скан при старте сам не запускается.
5. В таблице отметьте файлы галочками. Кнопка **Переместить в корзину** активна только при выборе.
6. Подтвердите действие. По умолчанию в диалоге стоит отмена.

Журналы пишутся на том компьютере, где открыли программу:

```text
%LOCALAPPDATA%\MediaDiskCleaner\
  logs\      app.log, operations.jsonl
  reports\   CSV и JSON отчёты
  settings\
```

На флешку логи не пишутся. На другом ПК журнал будет свой.

Тема переключается кнопкой внизу левого меню.

### Из исходников

Нужны Windows и Python 3.12+.

```bat
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```

## Безопасность

- Нет автоудаления и нет выбора файлов «за вас».
- Перед корзиной путь проверяется ещё раз: тип, расширение, корень скана, размер, время изменения.
- Нет `os.remove` / `unlink` / `rmtree` и нет удаления через командную строку.
- Системные каталоги, junction/symlink и опасные расширения не идут как медиа для очистки.
- Скрытые файлы по умолчанию пропускаются.
- EXE без манифеста администратора.

Тесты работают только во временных папках pytest и **не** трогают ваши диски и настоящую корзину.

```bat
python -m pytest tests -v
```

или `run_tests.bat`. Два теста на symlink могут быть `skipped` без привилегии разработчика в Windows — это нормально.

## Сборка EXE

Только на Windows. На машине, где будут пользоваться готовым файлом, Python не нужен.

```bat
python -m pip install -r requirements-build.txt
build.bat
```

`build.bat` сначала гоняет тесты, затем собирает **один** файл:

```text
dist\MediaDiskCleaner.exe
```

Первый запуск one-file чуть дольше: архив распаковывается во временную папку.

Для отладки с папкой библиотек рядом:

```bat
pyinstaller --noconfirm --clean MediaDiskCleaner.spec
```

Иконка необязательна: положите `resources/icons/app.ico`, если хотите свою. Каталоги `build\` и `dist\` в git не входят.

```text
MediaDiskCleaner.spec

```

---

## Чего в репозитории нет

Исходники и скрипты сборки — да. В git **не** попадают виртуальное окружение, `build/`, `dist/`, exe, логи, ключи, `.env` и пустые `.gitkeep`.

## Лицензии зависимостей

Приложение использует [PySide6](https://pypi.org/project/PySide6/) (Qt), [Pillow](https://pypi.org/project/pillow/) и [send2trash](https://pypi.org/project/Send2Trash/). При распространении EXE соблюдайте их лицензии.
